# Доработка проекта перед защитой

Полное описание — в отчёте «Отчёт_МИК_Банк.docx». Кратко:

## Клиентская часть (web/src)
- Единая дизайн-система (App.css, index.css): токены цветов и радиусов, светлая и тёмная темы, шрифт Onest.
- Переработаны все страницы: вход, главная, счета, платежи, валюта, профиль. Добавлен раздел «Операции».
- Глобальный поиск по операциям (⌘K / Ctrl+K), виджет «Траты за месяц», нижняя панель вкладок на телефоне.
- Окна операций: проверка ввода, доступный остаток, сумма на кнопке, расчёт обмена; окно не закрывается при ошибке.
- Подтверждение закрытия счёта, переименование счетов, скрытие баланса.
- Исправлено: знак процентов, потеря названий счетов, непонятные названия переводов, технические тексты ошибок входа.

## Серверная часть (core-service)
- Раздел «Операции»: OperationsController, OperationsService, PaymentService и вспомогательные классы.
- Таблица transaction_details (миграция 007) — категория и название магазина операции.
- Тесты: PercentAllocatorTest, PeriodWindowTest, MerchantCategoryResolverTest.

## Документация
- docs/operations-api.md — описание нового API.
- docs/demo/mik-bank-demo.html — демо интерфейса с тестовыми данными, открывается без сервера.

## Перед защитой
```
cd web && npm ci && npm run lint && npm run build
cd backend/banking-system-v1 && mvn test
```
